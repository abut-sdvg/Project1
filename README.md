# **AutoChronic**

## Идея проекта
интерактивная веб-платформа - систематизированный источник информации об автомобилестроении с интересными фактами, интерактивностью, визуализацией.

## Стек
HTML, CSS, Javascript, PHP, MySQL

## Запуск
На текущем этапе разработки проекта для запуска необходимо склонировать к себе проект и запустить index.html с помощью браузера
