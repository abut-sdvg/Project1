# Semantic map: AutoChronic

## Верхний уровень страницы

| Визуальный блок / содержание | Назначение | HTML-тег |
|---|---|---|
| Шапка с логотипом, меню и кнопкой Log in | Вводная часть страницы, повторяется на каждой странице | `<header>` |
| Логотип (изображение + ссылка) | Идентификация сайта, переход на главную | `<a><img></a>` |
| Меню «История / Бренды / Статистика» | Переходы по основным разделам сайта | `<nav>` |
| Список пунктов меню | Однородные элементы одного уровня | `<ul>` → `<li>` |
| Каждый пункт меню | Переход на конкретный раздел | `<a>` внутри `<li>` |
| Кнопка «Log in» | Переход на страницу/форму авторизации | `<a>` |
| Вся область ниже шапки | Уникальное содержимое страницы, единственный на странице | `<main>` |
| Нижняя панель с логотипом и подписью | Служебная информация, повторяется на каждой странице | `<footer>` |

## Содержимое main

Каждый крупный блок - отдельный `<section>`, так как у него есть собственный заголовок и он раскрывает свою тему.

### Section 1 - hero

| Элемент | Назначение | HTML-тег |
|---|---|---|
| «[01] - бейдж» | Декоративная пометка номера раздела, не самостоятельный контент | `<span>` |
| «Заголовок Autochronic» | Главный заголовок страницы, единственный h1 на странице | `<h1>` |
| «Описание» | Вводный текст, поясняющий идею продукта | `<p>` |
| Фоновое изображение | Иллюстративное/декоративное изображение | `<img alt="">` |
| Кнопка «Перейти к статьям» | Целевое действие — переход к списку статей | `<a>` |

### Section 2 — бренды

| Элемент | Назначение | HTML-тег |
|---|---|---|
| «[02] - бейдж» | Декоративная пометка номера раздела | `<span>` |
| «Заголовок» | Заголовок раздела, на уровень ниже h1 | `<h2>` |
| Обёртка вокруг 6 карточек брендов | Чисто техническая группировка для сетки, своего смысла не несёт | `<div>` |
| Карточка одного бренда | Самостоятельная единица контента — есть смысл сама по себе, вне списка | `<article>` |
| Иконка внутри карточки | Декоративный визуальный элемент карточки | `<div>` |
| Название бренда (Mercedes-Benz, BMW...) | Заголовок карточки, на уровень ниже h2 | `<h3>` |
| «EST. год» | Краткая характеристика бренда | `<p>` |

### Section 3 — таймлайн

| Элемент | Назначение | HTML-тег |
|---|---|---|
| «[03] - бейдж» | Декоративная пометка номера раздела | `<span>` |

## Спорные случаи

- **`<span>` для бейджа «[01]»–«[04]», а не `<div>`/`<p>`:** бейдж не является самостоятельным блоком с собственным смыслом, а лишь небольшой декоративной пометкой внутри контекста секции — это строчный (inline), а не блочный элемент.
- **`<article>` для карточек брендов/событий, а не `<div>`:** каждая карточка содержит законченный набор информации (название/год + краткая характеристика) и сохраняет смысл, если её показать отдельно от остальных карточек списка — это и есть критерий выбора `article`.
- **`<div>` только для обёртки-сетки вокруг карточек:** этот контейнер нужен исключительно для CSS-раскладки (grid/flex) и не несёт собственного смысла, поэтому не может быть `section` или `article`.
- **Иерархия заголовков `h1 → h2 → h3` без пропусков уровней:** `h1` — единственный на странице (в hero), `h2` — заголовки самих секций, `h3` — заголовки карточек внутри секций. Так как карточки вложены в section, у которой уже есть свой `h2`, заголовки карточек не могут быть `h2` повторно и не могут перескакивать сразу на `h3` мимо `h2` секции.
- **Кнопка «Log in» и «Перейти к статьям/в каталог» — `<a>`, а не `<button>`:** оба ведут на другую страницу (переход по URL), а не выполняют действие на текущей странице без перехода — это признак ссылки, а не кнопки.
- **Логотип - `<a>`, оборачивающий `<img>`:** кликабельный элемент, ведущий на главную страницу, поэтому оборачивается ссылкой, а изображение внутри неё - чисто визуальное представление.
