# Semantic map: AutoChronic
 
## Верхний уровень страницы
 
| Визуальный блок / содержание | Назначение | HTML-тег |
|---|---|---|
| Шапка с логотипом, меню и кнопкой «Войти» | Вводная часть страницы, повторяется на каждой странице | `<header>` |
| Логотип (изображение + ссылка) | Идентификация сайта, переход на главную | `<a><img></a>` |
| Меню «История / Бренды / Статистика» | Переходы по основным разделам сайта | `<nav aria-label="Навигация">` |
| Список пунктов меню | Однородные элементы одного уровня | `<ul>` → `<li>` |
| Кнопка «Войти» | Открывает формы входа/регистрации | `<button>` |
| Блок с формами входа и регистрации | Отдельный оверлей поверх страницы, не относится к основному контенту | `<div class="auth-overlay">` |
| Вся область с основным содержимым страницы | Уникальный контент страницы, единственный на странице | `<main>` |
| Нижняя панель с описанием проекта | Служебная информация, повторяется на каждой странице | `<footer>` |
  

## Блок авторизации (auth-overlay)
 
> Технически не внутри `<main>`, так как это не контент страницы, а
> служебный интерфейс (оверлей), который по умолчанию скрыт и появляется
> по клику на «Войти».

## Спорные случаи
 
- **`<span>` для бейджа «[01]»–«[04]», а не `<div>` или`<p>`:** бейдж - декоративная пометка внутри контекста секции, не самостоятельный блок, поэтому строчный `<span>`.
- **`<article>` для карточек брендов/событий/отзывов:** каждая карточка сохраняет смысл отдельно от списка - название+год, год+событие, цитата+автор.
- **`<div>` только для обёртки-сетки вокруг карточек:** нужен исключительно для CSS-раскладки, своего смысла не несёт.
- **Иерархия заголовков `h1 → h2 → h3` без пропусков уровней:** h1 один на странице, h2 - заголовки секций, h3 - заголовки карточек внутри них.
- На текущий момент страницы, на которые ведут ссылки (#Rules #Privacy #history #brands #statistics #articles), не реализованы, поэтому ссылки являются фиктивными.
